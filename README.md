# Website-Design
# ☕ Blue Aura Café

A modern and elegant café website designed with a soft, warm aesthetic and a simple user-friendly interface.

Blue Aura Café provides visitors with an enjoyable way to explore the café, browse the menu, view different categories, and find contact information.

---

## ✨ Features

- 🏠 **Home Page**
  - Elegant café introduction
  - Hero section
  - Popular menu categories
  - Quick access to the full menu

- 📖 **Full Menu**
  - Cold Drinks
  - Coffee
  - Snacks
  - Desserts
  - Interactive category navigation
  - Smooth scrolling between menu sections
  - Active category indicator

- 🌙 **Dark Mode**
  - Day and Night themes
  - Theme switching with the sun/moon button
  - Theme preference saved using `localStorage`
  - Different visual appearance for light and dark mode

- 📞 **Contact Page**
  - Phone number
  - Instagram
  - Email
  - Café address
  - Clean and organized contact card

- 🎨 **Responsive Design**
  - Designed primarily for mobile-sized screens
  - Clean card-based layout
  - Consistent visual identity across pages

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG Icons
- Google Fonts
- LocalStorage API
